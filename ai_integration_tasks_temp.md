# Задачи по интеграции ИИ (из ТЗ Admin Panel)
*Фронтенд и базовый бэкенд исключены, выписано ДОСЛОВНО только то, что касается AI, токенов, метрик и оркестрации нейросетей.*

## 3. Dashboard
* **Использование токенов**: Суммарный расход токенов LLM за сегодня/неделю
* **Стоимость по LLM**: Затраты платформы на все модели за период
* **Среднее время ответа**: Средняя latency по всем capability-вызовам
* **Графики**: 
  * Токены по дням (стек по моделям: GPT / Claude / Gemini)
  * Количество запросов (по агентам)
  * Использование моделей (доли, %)
  * Ошибки (по типам: timeout, validation, API-сбой)
  * Стоимость AI по дням, с прогнозом на конец месяца

## 5. Компании (Tenants)
* **Токены и стоимость**: Расход токенов и стоимость AI по данному tenant за период
* **AI Usage**: Детальная разбивка использования AI по агентам и capability для этой компании

## Управление AI-платформой (Разделы 7 - 12)
* **7. Агенты (Agent Manager)**: Назначение агента, список capability, модели (какие LLM использует, приоритет и fallback), инструменты, ограничения (таймаут, лимиты), максимальный параллелизм.
* **8. Capability Registry**: Реестр атомарных действий. (Версия, Модель, Ссылка на Prompt, Validator правил, Timeout, Next capability).
* **9. Prompt Registry**: Управление системными промптами. (ROLE, MISSION, RULES, OUTPUT, EXAMPLES, Версионирование, Diff, Rollback).
* **10. Workflow Manager**: Управление сквозными сценариями. Визуальный редактор (DAG) — узлы это capability/agent-вызовы.
* **11. Tool Registry**: Реестр внешних интеграций (LLM: OpenAI, Claude, Gemini, HeyGen, Kling).
* **12. Model Router**: Настройка маршрутизации задач между разными LLM в зависимости от типа задачи. (Текст -> GPT-5, Анализ -> Claude, Большой контекст -> Gemini). Fallback-цепочка. Статистика по каждому маршруту: объём запросов, средняя стоимость, latency.

## 13. Очередь задач
* Все выполняющиеся и ожидающие задачи платформы в реальном времени.

## 14. История Workflow
* **Стоимость** — затраты на токены/API по каждому шагу
* **Результат** — итоговый успех/неудача, с детальным выводом на каждом шаге (input / ошибка).

## 15. AI Monitoring
Специализированная observability-панель для AI-слоя платформы:
* **Latency**: Время ответа модели/capability, по перцентилям (p50/p95/p99)
* **Tokens**: Расход токенов по запросам, в разбивке по моделям
* **Cost**: Стоимость в реальном времени, по агентам/tenant/моделям
* **Errors**: Частота и типы ошибок
* **Retries / Fallback Models / Prompt Version / Completion Time**

## 16. Логи
* Детализация записи (Input, Prompt с версией, Model, Output, Validation).

## 21. Центр тестирования
Инструмент для прогона любой связки capability + prompt + model на тестовых данных без влияния на продакшн.
* **Prompt** — финальный текст промпта, отправленный модели
* **Context** — какой контекст был подставлен (Business Memory и т.д.)
* **LLM Response** — сырой ответ модели
* **Validation** — результат проверки валидатором
* **Стоимость** — сколько стоил этот тестовый прогон
* **Время** — сколько заняло выполнение

## 24. Стоимость и токены (/admin/costs)
Детальная финансовая картина по расходам платформы на AI.
* **GPT**: Токены, стоимость, число запросов
* **Claude**: Токены, стоимость, число запросов
* **Gemini**: Токены, стоимость, число запросов
* **HeyGen**: Минуты видео, стоимость
* **Kling**: Число генераций видео, стоимость
* **Итоговые показатели**: Суммарные затраты, суммарный расход токенов, % использования лимита, прогноз затрат до конца периода.
